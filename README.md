# 🍕 Pizza Sales Data Analytics Dashboard

## 📊 Project Overview

This project is an Excel-based **Pizza Sales Data Analytics Dashboard** designed to analyze pizza sales data and provide meaningful insights into business performance.

The dashboard presents sales analysis covering total revenue, total orders, pizzas sold, average order value, pizza categories, pizza sizes, best-selling pizzas, and daily and monthly sales trends.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze total pizza sales and revenue
- Understand total orders and pizzas sold
- Calculate average order value
- Analyze daily and monthly sales trends
- Compare sales across different pizza categories
- Understand customer preferences for different pizza sizes
- Identify best-selling pizzas
- Identify least-selling pizzas
- Analyze sales performance over time
- Present sales data through an interactive dashboard

## 📈 Dashboard Analysis

### Sales Performance Analysis

The dashboard displays overall sales performance through key metrics such as total revenue, total orders, and total pizzas sold.

### Order Analysis

Orders are analyzed to understand customer purchasing patterns and overall sales activity.

### Daily Sales Analysis

The dashboard analyzes daily order trends to identify variations in customer demand throughout the week.

### Monthly Sales Analysis

Monthly sales trends help compare performance across different months and identify periods of higher or lower sales.

### Pizza Category Analysis

The dashboard compares sales across pizza categories to understand which categories contribute most to overall sales.

### Pizza Size Analysis

Pizza sales are analyzed by size to understand customer preferences and purchasing patterns.

### Best-Selling Pizza Analysis

The dashboard identifies the top-performing pizzas based on sales or quantity sold.

### Least-Selling Pizza Analysis

The dashboard highlights lower-performing pizzas to help understand product demand and sales performance.

## 📅 Sales Report

The dashboard provides daily and monthly sales analysis, allowing comparisons across different time periods to identify trends and patterns in pizza sales.
